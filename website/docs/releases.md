# Releases

Branch Schematic is currently in an invite-only alpha test. This page will list official releases as they become available.

## Official Releases

An official release is added here only when it has one of these authoritative sources:

- A published GitHub Release
- A Git tag associated with the release

Ordinary commits, development builds, and internal milestones are not presented as official releases. The first official release will appear here when it is published.
