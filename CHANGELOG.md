# Changelog

All notable changes to Branch Schematic will be documented here.

## [0.1.0] - Unreleased

### Added

- Track local repositories and clone GitHub repositories into the workspace.
- View repository status, branches, recent commits, changed files, and diffs.
- Perform common Git operations including checkout, fetch, fast-forward pull, push, staging, unstaging, and commit creation.
- Organize repositories and branches in a canvas workspace with draggable cards, branch relationships, pan and zoom controls, saved views, and persisted layout.
- Group, favorite, tag, archive, restore, and rename tracked repositories for easier workspace organization.
- View branch topology and commit timelines using cached repository history.
- Recover tracked repositories when their local paths are temporarily unavailable.
